Azure Wiki
Descripción del proyecto

Azure Wiki es una aplicación web educativa que tiene como objetivo explicar qué es Microsoft Azure, sus principales características, beneficios y servicios de computación en la nube.

La plataforma permite consultar documentación organizada por categorías, leer artículos educativos y buscar conceptos relacionados con Microsoft Azure.
